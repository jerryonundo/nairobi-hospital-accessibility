# Data Sources and Documentation

This document records the datasets used in the Spatial Assessment of Hospital Accessibility in Nairobi County, Kenya.

| Dataset | Source | Application |
|---|---|---|
| Hospital locations | OpenStreetMap | Healthcare facility locations |
| Road network | Geofabrik / OpenStreetMap | Road-network accessibility analysis |
| Population estimates | WorldPop 2025 | Population distribution and estimation |
| County boundary | GADM | Nairobi County study-area boundary |
| Ward boundaries | Humanitarian Data Exchange (HDX) | Ward-level analysis |

## Coordinate Reference System

The projected coordinate reference system used for the analysis was:

**EPSG:32737 — WGS 84 / UTM zone 37S**

## Data Access

- OpenStreetMap: https://www.openstreetmap.org/
- Geofabrik Kenya: https://download.geofabrik.de/africa/kenya.html
- WorldPop: https://www.worldpop.org/
- GADM: https://gadm.org/
- HDX Kenya ward boundaries: https://data.humdata.org/dataset/administrative-wards-in-kenya-1450
